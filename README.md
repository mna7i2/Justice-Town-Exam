# ⚖ Justice Town — موقع اختبار التفعيل

الموقع **للإدارة بس** — المواطن ما يدخله:

1. الإداري يضغط **دخول بحساب Discord** — ما يدخل إلا اللي عنده **رتبة قسم التفعيل** (بدون بوت ولا كلمة سر).
2. يكتب يوزر المواطن ← لو عليه تايم أوت يطلع **❌ مرفوض** مع الوقت الباقي، ولو متفعل يطلع مين فعّله.
3. يشارك شاشته مع المواطن في الدسكورد ويبدأ الاختبار، والمواطن يقول له الأجوبة.
4. **ما يقدر يسلّم لين يكتب آيدي المواطن.**
5. نجح ← ينسجل متفعل باسم الإداري. رسب ← تايم أوت 72 ساعة.
6. رسالة توصل الروم (الويب هوك): منشن الإداري، وتحته منشن المواطن، مع النتيجة كاملة.

لوحة `/admin` فيها كل النتائج والسجل وفتح محاولات جديدة.

## ✏ تعديل الأسئلة

افتح `config/questions.json`. كل سؤال كذا:

```json
{
  "question": "وش معنى RDM؟",
  "options": ["قتل بدون سبب", "صدم بالسيارة", "ميتا قيمنق"],
  "answer": 1
}
```

- `answer` = **رقم** الخيار الصحيح (1 = الأول، 2 = الثاني…) أو نص الخيار الصحيح بالضبط.
- تقدر تحط خيارين (صح/خطأ) أو أكثر لين 8.
- التعديل يشتغل **فوراً** بدون ما تعيد تشغيل الموقع.
- الأجوبة الصحيحة ما توصل للمتصفح أبداً — التصحيح كله في السيرفر، فما أحد يقدر يغش من الكود.

**الإعدادات (`settings`):**

| الإعداد | المعنى |
|---|---|
| `passScore` | كم إجابة صحيحة لازم للنجاح (حالياً 25). إذا حطيته `0` يستخدم `passPercent` بدله |
| `passPercent` | نسبة النجاح — تُستخدم بس إذا `passScore` = 0 |
| `questionCount` | كم سؤال يطلع لكل لاعب (حالياً 30 ينسحبون عشوائياً من بنك الـ 250). `0` = كلهم |
| `timeLimitMinutes` | وقت الاختبار بالدقايق. `0` = بدون وقت |
| `cooldownMinutes` | التايم أوت للراسب أو المرفوض قبل يعيد (حالياً 4320 = 72 ساعة). للمرفوض يبدأ من وقت الرفض |
| `maxAttempts` | أقصى عدد محاولات. `0` = مفتوح |
| `shuffleQuestions` / `shuffleOptions` | خلط ترتيب الأسئلة والخيارات |
| `showReview` | `true` = بعد الاختبار يشوف اللاعب الصح والغلط (ما أنصح فيه، يسهل تسريب الأجوبة) |

## ⚙ الخطوة 1: الإعدادات

ما تحتاج بوت. على Render في **Environment** (أو في ملف `.env` على جهازك):

```
SESSION_SECRET=كلام-عشوائي-طويل-40-حرف-أو-أكثر
DISCORD_CLIENT_ID=          ← من Developer Portal ← OAuth2
DISCORD_CLIENT_SECRET=      ← من Developer Portal ← OAuth2 ← Reset Secret
DISCORD_GUILD_ID=           ← آيدي السيرفر (Copy Server ID)
ADMIN_ROLE_ID=              ← آيدي رتبة قسم التفعيل (Copy Role ID)
ADMIN_IDS=                  ← اختياري: أشخاص يدخلون حتى بدون الرتبة
DISCORD_WEBHOOK_URL=        ← اختياري: عشان توصل النتائج لروم في الدسكورد
DISCORD_INVITE_URL=         ← اختياري: رابط دعوة السيرفر
```

**تطبيق الدسكورد (للدخول):** https://discord.com/developers/applications ← **New Application** ← **OAuth2** ← انسخ **Client ID** و **Client Secret** ← في **Redirects** ضيف `https://رابط-موقعك/auth/callback` ← **Save**. ما تحتاج تسوي بوت ولا تضيفه للسيرفر.

**رابط الويب هوك (اختياري):** في الدسكورد ← إعدادات روم النتائج ← **Integrations** ← **Webhooks** ← **New Webhook** ← **Copy Webhook URL**.

## 🌍 الخطوة 3: رفع الموقع على الإنترنت

الموقع يحتاج **سيرفر Node.js شغّال 24 ساعة** (مو استضافة صفحات ثابتة)، لأنه هو اللي يصحح الاختبار ويحفظ النتائج.

### الخيار أ — Google Cloud (فيه سيرفر مجاني دائم)

1. ادخل https://console.cloud.google.com ← **Compute Engine** ← **Create Instance**.
2. اختر: النوع **e2-micro**، المنطقة **us-central1** أو **us-east1** أو **us-west1** (هذي اللي مجانية)، النظام **Ubuntu 24.04**، وعلّم **Allow HTTP** و **Allow HTTPS**.
3. افتح **SSH** من الصفحة واكتب:

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - && sudo apt-get install -y nodejs
```

4. ارفع مجلد المشروع (زر **Upload file** في نافذة SSH، أو عن طريق GitHub)، ثم داخل المجلد:

```bash
npm install --omit=dev && sudo npm i -g pm2 && pm2 start server.js --name justice-exam && pm2 save && pm2 startup
```

5. اربط دومين واعمل HTTPS (أسهل طريقة: [Caddy](https://caddyserver.com) — سطر واحد يسوي لك شهادة SSL تلقائياً):
   ```
   exam.justicetown.com {
     reverse_proxy localhost:3000
   }
   ```

### الخيار ب — عندك VPS حق سيرفر FiveM؟

نفس خطوات 3 و 4 فوق بالضبط، وتشغله جنب السيرفر.

### الخيار ج — Railway (أسهل، بس مدفوع بعد الفترة المجانية)

ارفع المشروع على GitHub ← https://railway.app ← New Project ← Deploy from GitHub ← حط متغيرات `.env` في **Variables** ← أضف **Volume** على المسار `/app/data` عشان النتائج ما تنحذف.

> بعد ما ترفع، لا تنسى: غيّر `BASE_URL` للرابط الجديد، وأضف `https://رابطك/auth/callback` في Redirects حق Discord.

## 🛡 لوحة النتائج `/admin`

تدخلها **بحسابك في الدسكورد** (نفس دخول الصفحة الرئيسية). لو انشالت منك الرتبة، تنقفل عليك خلال 6 ساعات بالكثير.

> عشان تنسخ أي آيدي: Discord ← الإعدادات ← Advanced ← فعّل **Developer Mode** ← اضغط على الشخص يمين ← **Copy User ID**.

فيها:
- إحصائيات: كم ناجح وراسب ونسبة النجاح.
- كل محاولة بالتفصيل: يوزر المواطن، مين الإداري، وش جاوب على كل سؤال، وكم أخذ وقت.
- **سجل الإدارة**: الإداري وتحته المواطن، نجح أو رسب، ومتى.
- **فتح محاولات جديدة** لمواطن (يشيل عنه التايم أوت).
- أصعب الأسئلة (اللي أغلب الناس يغلطون فيها).

> ⚠ لو ما حطيت `DISCORD_CLIENT_ID` و `DISCORD_CLIENT_SECRET`، يرجع الدخول القديم (اسم + آيدي) وأي أحد يقدر ينتحل إداري.

## ❓ مشاكل شائعة

| المشكلة | الحل |
|---|---|
| "ما عندك رتبة قسم التفعيل" | أعطه الرتبة في السيرفر، أو تأكد من `ADMIN_ROLE_ID` و `DISCORD_GUILD_ID` |
| بعد الدخول يقول Discord "Invalid redirect_uri" | ضيف `https://رابط-موقعك/auth/callback` بالضبط في Redirects حق التطبيق |
| النتائج ما توصل للروم | تأكد من `DISCORD_WEBHOOK_URL` (لازم يبدأ بـ `https://discord.com/api/webhooks/`) |
| الإداريين ينطردون من اللوحة كل شوي | حط `SESSION_SECRET` ثابت في Environment |
