# 🚗 Justice Town — معرض السيارات

موقع المعرض: المواطن يشوف السيارات (الصورة، الاسم، الفئة، السعر، الكمية، متوفر أو لا) ويقدر يفلتر حسب الفئة **A / B / C / D**.
الإداريين عندهم صفحة مخفية (`/admin`) يضيفون فيها السيارات ويعدلون الأسعار والكميات والصور ويحذفون.

---

## 📁 الملفات

| الملف | وش فيه |
|---|---|
| `server.js` | السيرفر والحماية |
| `storage.js` | حفظ السيارات والصور (MongoDB أو ملف) |
| `public/` | صفحة المعرض |
| `views/admin.html` + `public/admin.js` | صفحة الإدارة |

---

## ⚙ الإعدادات (Environment في Render)

| المتغير | لازم؟ | المعنى |
|---|---|---|
| `ADMIN_PASSWORD` | ✅ | كلمة سر صفحة الإدارة (8 أحرف على الأقل) |
| `MONGODB_URI` | ✅ على Render | عشان السيارات ما تنمسح — شوف تحت |
| `SESSION_SECRET` | مستحسن | كلام عشوائي طويل |
| `ADMIN_PATH` | اختياري | تغيير رابط الإدارة لشي سري، مثل `staff-garage-77` |
| `DISCORD_INVITE_URL` | اختياري | زر Discord |
| `SERVER_URL` | اختياري | زر "صفحة السيرفر" (مثلاً رابط موقع الاختبار) |

## 🗄 MongoDB Atlas (مجاني) — ليش لازم؟

Render المجاني يمسح أي ملف ينحفظ في الموقع كل ما يعيد التشغيل (ويعيد التشغيل كثير). يعني بدون قاعدة بيانات، السيارات اللي يضيفها الإداري **بتختفي**.

1. ادخل https://www.mongodb.com/cloud/atlas/register وسوّ حساب.
2. **Create** ← اختر **M0 (Free)** ← **Create Deployment**.
3. يطلب منك تسوي **Database User**: حط يوزر وكلمة سر (انسخهم عندك).
4. **Network Access** ← **Add IP Address** ← **Allow Access from Anywhere** (`0.0.0.0/0`) ← Confirm.
5. **Database** ← **Connect** ← **Drivers** ← انسخ الرابط اللي شكله:
   `mongodb+srv://USER:<db_password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority`
6. بدّل `<db_password>` بكلمة سر اليوزر، وحط الرابط كامل في Render ← **Environment** ← `MONGODB_URI`.

لما يشتغل صح بتشوف في Logs: `✔ متصل بـ MongoDB — السيارات محفوظة دائماً`، والتنبيه الأصفر في صفحة الإدارة يختفي.

## 🛡 صفحة الإدارة

- ادخل `https://رابطك/admin` (أو المسار اللي حطيته في `ADMIN_PATH`) ← اسمك + كلمة السر.
- **+ إضافة سيارة**: صورة (تتصغر تلقائياً)، الاسم، الفئة (A / B / C / D)، السعر، الكمية، وصف قصير اختياري.
- أزرار **− / +** تغير الكمية بسرعة. الكمية **0** = تطلع للمواطنين **غير متوفر**.
- **تعديل** / **حذف**. اسم الإداري ينسجل على كل سيارة (أضافها / آخر تعديل) — وما يبين للمواطنين.
- الصفحة ما لها أي رابط في الموقع، وما تنفتح بدون كلمة السر.

## 🔒 الحماية

- كل شي ينفحص في السيرفر: الأسعار والكميات أرقام بس، والنصوص تنعرض كنص (ما ينفع أحد يحط كود).
- الصور تنفحص إنها صور حقيقية (JPG / PNG / WebP) وحدها 2.5MB.
- 5 محاولات دخول بالدقيقة بس — ما ينفع تخمين كلمة السر.
- الطلبات من مواقع ثانية مرفوضة، والجلسة موقعة ومشفرة.
